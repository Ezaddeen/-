1 تثبيت PHP إصدار 8.2 أو أحدث على نظام Windows

يجب أن تتوفر الامتدادات التالية

pdo_sqlite
sqlite3
mbstring
openssl
fileinfo
ctype
json
tokenizer
xml
dom
curl

تحقق من تثبيت PHP بالأمرين التاليين

php -v

php -m

يجب أن يظهر sqlite3 و pdo_sqlite في النتيجة

2 تثبيت Composer

نزّل Composer من موقع Composer الرسمي

أعد فتح PowerShell ثم تحقق من التثبيت

composer -V

3 تثبيت Node.js و npm

ينصح بتثبيت نسخة Node.js LTS إصدار 20 أو أحدث

تحقق من التثبيت

node -v

npm -v

4 تثبيت Git عند الحاجة إلى تنزيل المشروع من مستودع

git --version

5 فتح مجلد المشروع

افتح PowerShell داخل مجلد بصمة انامل

انتقل إلى مجلد تطبيق Laravel بالأمر التالي

cd laravel-app

تأكد من وجود الملفات التالية داخل المجلد

artisan

composer.json

package.json

database

resources

routes



إن كان جهازك يدعم SQLite فاستخدم الإعدادات التالية في ملف البيئة

DB_CONNECTION=sqlite

SESSION_DRIVER=database

QUEUE_CONNECTION=database

CACHE_STORE=database

MAIL_MAILER=log

لا تضع مفاتيح حقيقية أو كلمات مرور إنتاجية في ملفات المشروع

7 تثبيت حزم PHP

composer install

8 تثبيت حزم الواجهة

npm install

9 إنشاء مفتاح تشفير Laravel

php artisan key:generate

10 إنشاء ملف قاعدة بيانات SQLite

New-Item -ItemType File -Force database/database.sqlite

11 تنفيذ ترحيلات قاعدة البيانات

php artisan migrate

12 إضافة بيانات العرض وحساب المدير التجريبي

php artisan db:seed

بيانات حساب المدير التجريبي

البريد الإلكتروني admin@basmat-anamil.com

كلمة المرور Admin12345!

يمكن تغيير بيانات المدير في ملف البيئة قبل تشغيل Seeder

ADMIN_NAME=مدير بصمة الحرفيين

ADMIN_EMAIL=admin@example.com

ADMIN_PASSWORD=كلمة مرور قوية

لتحديث حساب المدير بعد تغيير بياناته نفذ الأمر التالي

php artisan db:seed --class=Database\Seeders\AdminUserSeeder

php artisan optimize:clear

تحذير لا تستخدم الأمر التالي مع بيانات حقيقية لأنه يحذف قاعدة البيانات ويعيد إنشائها

php artisan migrate:fresh --seed

13 تشغيل خادم Laravel

افتح نافذة PowerShell داخل مجلد laravel-app نفذ الأمر التالي واترك النافذة مفتوحة

php artisan serve

عنوانه عادة هو

http://127.0.0.1:8000

14 تشغيل واجهة Vite

افتح نافذة PowerShell ثانية داخل مجلد laravel-app نفذ الأمر التالي واترك النافذة مفتوحة

npm run dev

15 بديل تشغيل الخوادم من أمر واحد

composer run dev

16 فتح الصفحات الرئيسية

واجهة المتجر

http://127.0.0.1:8000

تسجيل الدخول

http://127.0.0.1:8000/login

إنشاء حساب

http://127.0.0.1:8000/register

لوحة المدير

http://127.0.0.1:8000/admin

مساحة البائع

http://127.0.0.1:8000/seller

17 تشغيل اختبارات المشروع

php artisan test

18 فحص تنسيق PHP

vendor/bin/pint --test

19 إنشاء ملفات الواجهة للإنتاج

npm run build

20 إعداد MySQL اختياريًا

لا يلزم MySQL للتشغيل المحلي لأن SQLite هو الإعداد الافتراضي

إن أردت استخدام MySQL أنشئ قاعدة بيانات باسم basmat_anamil ثم عدل إعدادات ملف البيئة كالتالي

DB_CONNECTION=mysql

DB_HOST=127.0.0.1

DB_PORT=3306

DB_DATABASE=basmat_anamil

DB_USERNAME=root

DB_PASSWORD=

ثم نفذ

php artisan config:clear

php artisan migrate --seed
